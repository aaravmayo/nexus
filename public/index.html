Is it really just one line of code?

Yes. Save or host the included nexus.js widget and add a single script tag to your website. The script creates its own interface and keeps its styles isolated from your site using Shadow DOM.

Will it work with my existing website?

The widget works on pages that allow custom JavaScript. That includes plain HTML sites and many popular CMS and website builders. Framework-based sites should load the script on the client, using their supported script-loading approach.

Can I change the assistant's name?

Absolutely. Add data-name="Your assistant" to the script tag. You can also change the widget's colors and copy in nexus.js.

Does this preview use a real AI model?

No. This is an interactive frontend concept with simulated responses. Live AI requires a server-side integration, a knowledge source, and suitable authentication and usage limits. Never put a private AI API key in browser JavaScript.

 The one-line installation

Small snippet. Big hello.

The included widget can run on any page that supports custom JavaScript.

<script src="./nexus.js" defer></script>
  1. Place nexus.js beside your HTML file.
  2. Paste the script before the closing body tag.
  3. Open your website and start a conversation.

For another website, host nexus.js and use its absolute HTTPS URL. This widget uses simulated replies. A live AI service needs a backend; private API keys must never be placed in the embed.
